Project #20 Specification

Automated Neural Tractography Streamline Quality Control

Target Industry Profile: QMENTA, Connectomics Analytics Groups

1. System Architecture & Concept

3D Streamline geometric feature extractor paired with an Isolation Forest unsupervised anomaly detector for filtering false-positive dMRI tracks.

2. Synthetic Bio-Data Engineering Strategy

3D streamline coordinate trajectories representing anatomical fiber tracts (e.g., corticospinal tract) with injected spurious curves.

3. Low-End LLM Prompt & Module Blueprint

  • Module 1: Synthetic Streamline Generator: Generate 3D point sequences modeling plausible anatomical tracts and spurious anatomical outliers.
  • Module 2: Geometric Feature Extractor: Compute streamline length, curvature, torsion, and end-point spatial coordinates.
  • Module 3: Isolation Forest Outlier Cleaner: Train Isolation Forest model to filter out false-positive fiber tracks.

4. Core Technical Starter Skeleton

import numpy as np
from sklearn.ensemble import IsolationForest

def extract_streamline_features(streamline_3d):
    # streamline_3d shape: (num_points, 3)
    diffs = np.diff(streamline_3d, axis=0)
    segment_lengths = np.linalg.norm(diffs, axis=1)
    total_length = np.sum(segment_lengths)
    start_point = streamline_3d[0]
    end_point = streamline_3d[-1]
    return np.concatenate([[total_length], start_point, end_point])
